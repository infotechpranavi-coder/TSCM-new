CRITICAL IMPLEMENTATION NOTES (Next.js — REQUIRED)
================================================================================

1. ON-PAGE MATCH RULE (FAQPage & HowTo)
   Google penalizes "hidden schema." FAQPage on /corporate-tscm-service or HowTo on
   blog posts is ONLY allowed if JSON-LD text matches visible on-page content
   word-for-word. If users cannot read it on screen, do not add the schema.

2. NEXT.JS JSON-LD INJECTION (prevent build/render breaks)
   Do not paste raw JSON with unescaped & or quotes into JSX. Use:

   <script
     type="application/ld+json"
     dangerouslySetInnerHTML={{ __html: JSON.stringify(schemaGraph) }}
   />

   Recommended: create src/components/JsonLd.tsx that accepts a schema object.

3. POST-DEPLOYMENT VALIDATION
   After staging or live deploy, test every template with:
   - Google Rich Results Test: https://search.google.com/test/rich-results
   - Schema Markup Validator: https://validator.schema.org/
   Fix all errors and warnings before treating a page as complete.
